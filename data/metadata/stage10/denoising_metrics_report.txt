3. THREE-WAY METRIC EVALUATION FRAMEWORK
--------------------------------------------------
Comparison A: Clean Reference vs Noisy Input
  - Reference (I): Clean Baseline (Stage 5)
  - Evaluated (K): Noisy Input (Stage 8)
  - Scientific Meaning: Quantifies severity of synthetic noise degradation.

Comparison B: Clean Reference vs Denoised Output
  - Reference (I): Clean Baseline (Stage 5)
  - Evaluated (K): Denoised Output (Stage 9)
  - Scientific Meaning: Primary quantitative measure of restoration fidelity.

Comparison C: Noisy Input vs Denoised Output
  - Reference (I): Noisy Input (Stage 8)
  - Evaluated (K): Denoised Output (Stage 9)
  - Scientific Meaning: Quantifies magnitude of filtering modification.
  - Note: Comparison C alone does NOT measure restoration accuracy.

4. METRIC DEFINITIONS & FORMULAS
--------------------------------------------------
1. MSE   : (1/N) * sum((I - K)^2)
2. PSNR  : 10 * log10(1.0 / MSE) [dB], safe handling of MSE=0 -> +inf
3. SSIM  : structural_similarity(I, K, data_range=1.0, win_size=7)
4. SNR   : 10 * log10(sum(I^2) / sum((I - K)^2)) [dB] (Reference Signal Energy)
5. MAE   : (1/N) * sum(|I - K|)
6. RMSE  : sqrt(MSE)
7. Entropy: Shannon Information Entropy (256 bins)
8. Gradient: Mean Sobel Gradient Magnitude (ksize=3)
9. CNR   : |mu_ROI - mu_BG| / sqrt(sigma_ROI^2 + sigma_BG^2) (Standard AAPM/ICRU)
10. Foreground: Separate Breast-Region metrics excluding exterior black air
