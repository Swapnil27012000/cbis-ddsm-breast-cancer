1. SUMMARY OF IMPLEMENTATION
--------------------------------------------------------------------------------
To resolve the Stage 16.2 overwrite vulnerability, smoke-test paths have been
separated from full-training production paths via a two-tier defense-in-depth:
1. Directory separation:
   Smoke tests write exclusively to:
     models/stage16_smoke_tests/<canonical_model>/
     results/stage16_smoke_tests/<canonical_model>/
2. Filename prefixing:
   All smoke-test checkpoints are prefixed with "smoke_":
     smoke_<canonical_model>_best_loss.pt
     smoke_<canonical_model>_best_auc.pt
     smoke_<canonical_model>_final.pt
3. Artifact redirection:
   All history CSVs, metric CSVs, and config files for smoke tests are redirected
   to distinct "smoke_" filenames in data/metadata/stage16/.
4. Production path preservation:
   Full-training paths (smoke_test=False) remain 100% unchanged:
     models/stage16_densenet121/densenet121_best_loss.pt
     models/stage16_densenet121/densenet121_best_auc.pt
     models/stage16_densenet121/densenet121_final.pt
     models/stage16_efficientnet_b0/efficientnet_b0_best_loss.pt
     models/stage16_efficientnet_b0/efficientnet_b0_best_auc.pt
     models/stage16_efficientnet_b0/efficientnet_b0_final.pt
